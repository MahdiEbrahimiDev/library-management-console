# 📚 Library Management Console

A simple **Library Management System** built with **C#** as a console application.

### ✨ Features

* Add and manage books
* Manage library members
* Borrow and return books
* Basic library management operations

### 🛠️ Technologies

* C#
* .NET
* Object-Oriented Programming (OOP)

### 🚀 Run

```bash
git clone https://github.com/MahdiEbrahimiDev/library-management-console.git
cd library-management-console
dotnet run
```
